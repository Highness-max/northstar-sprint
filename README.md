# Northstar Retail - Support Deflection MVP

## 🚀 Project Overview
This prototype reduces manual support tickets for *Order Status* and *Returns/Refunds*. Users enter their order ID and get instant updates without talking to a human.

## 🛠️ How to Run
Double-click index.html in any web browser. No installation needed.
