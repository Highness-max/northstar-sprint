1. WHAT WORKS (MVP covers 2 ticket types):
   - Order Status: Works perfectly for 7 mock orders (#1001 to #1007). Shows colored badges (Processing/Shipped/Delivered) and an Apple-style progress stepper.
   - Returns/Refunds: Works perfectly. Displays "Approved", "Pending", or "No refund" messages with clear status badges.
   - Deflection Strategy: If an order isn't found, the bot offers an "Open support ticket" button that auto-fills the order ID—proving we reduce manual ticket creation.
   - Clear Button: Quickly resets the Order Status input.
   - Copy Button: Copies order ID to clipboard with one click.
   - Dark Mode: Toggle between light and dark themes for accessibility.
   - Total Orders Counter: Shows the number of orders in the database.
   - Loading Spinner: Simulates API response for better UX.

   - The database is hardcoded (mock data)—not connected to Northstar's real API yet.
   - The "Copy" button requires HTTPS or localhost for clipboard access in some browsers.
